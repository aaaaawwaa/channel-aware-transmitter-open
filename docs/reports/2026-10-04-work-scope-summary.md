# 作品功能收敛与新开发方向

日期：2026-10-04。用户已选择“教学演示＋环境诊断”，BPSK必交、QPSK条件扩展、建议人工确认。原规划交付作品简介、增减清单与执行计划。后续用户批准开始开发：S1教学入口/真实接收星座/实验记录已离线实现，候选c3bf915c未安装；S2/S3与实板门禁尚未完成。最新状态见[阶段报告](2026-10-04-s1-teaching-development.md)。

建议名称：**基于Zynq与AD9361的便携式通信教学与环境诊断平台**。

## 收敛后的作品简介（目标版）

本作品面向通信教学与可控射频实验，以Zynq SoC和AD9361为核心，设计集BPSK信号生成、有限IQ采集、接收分析与环境诊断于一体的便携式平台。系统通过五寸触摸屏完成参数配置，展示时域、频谱、接收星座、同步状态与误码统计，并保存实验数据用于回放和对比。PL承担样点传输与有限采集，PS负责设备控制和快照分析。平台在已知实验条件下利用时域、频域特征判断窄带干扰和脉冲异常，给出附带依据的处理建议；参数调整由操作员确认并通过既有控制流程加载。系统保留停止、解除布防和异常拒绝机制，通过离线回放与TX1→RX1有线回环分阶段验证，形成可观测、可解释、可复现的通信实验工具。QPSK作为核心功能完成后的扩展。

“接收星座、环境诊断和环境建议”是新计划内容，对外汇报未验收前使用“拟增加/设计目标”，不写成当前已完成。

## 为什么这样收敛

原简介同时承诺多制式收发、RRC/EVM、异常识别与自动档位决策，验收链条过长。新主线用已测BPSK作为完整实验载体，把新增工作投入“看到真实接收过程、解释异常、保存证据”，智能部分采用有限场景的可解释诊断与人工建议。

现有CNN调制识别保留辅助，不用它代替环境分类；现有理想发射星座不能冒充真实接收星座；PS软件成形/同步不能写成PL实时算法。

## 功能增减

| 处置 | 内容 |
|---|---|
| 必交保留 | BPSK3M RECT生成/接收、显式PRBS参考与BER、4096点有限IQ、时域/频谱/码值、触摸控制、取消/停止/解除/失效 |
| 必交新增 | 同帧真实接收星座、实验IQ/配置/结果记录、受控窗口内窄带/脉冲诊断、诊断依据、人工确认建议/拒绝 |
| 条件扩展 | QPSK3M RECT独立接收；第二档资格与效果证据通过后提供档位调整演示 |
| 暂缓 | BPSK2/3/5M全面扩展、RRC接收、QAM16/64接收、天线场景迁移 |
| 退出本轮承诺 | EVM、校准SNR/dBm、CRC/协议帧、连续接收、自动换频/选制式/发射 |
| 高级工具保留 | 既有QAM/RRC发射、ACM2108工具、CNN调制识别及可靠回退；教学入口不把它们当接收验收成果 |

删减发生在交付范围与后续教学界面，不删除已验证底层功能或裁剪已冻结模型类别。

## 新总体Plan

| 阶段 | 主要交付 | 完成门禁 |
|---|---|---|
| S0 当前版本收尾 | 补齐M4剩余真人失效/取消/停止解除/OFF确认 | 已拍正常项不重复；安全与失效问题闭合 |
| S1 下一开发 | 教学入口、真实接收星座、实验数据保存/回放 | 原BPSK不退化；同帧、可回放、三会话新实板及真人可用 |
| S2 环境诊断 | 固定BPSK域的正常窗口/窄带/脉冲及无法判断/无效 | 90已知有线＋18安全有线负控＋12离线拒绝输入分开报告，阈值不看测试集；逐类≥27/30正确 |
| S3 人工建议 | 验证档位表、规则依据、仅填草稿、人工加载 | 无资格/过期/无收益不推荐调整；停止解除可靠 |
| S4 核心演示 | 正常、窄带、脉冲、拒绝四场景，保存报告与真人时延 | 功能/资源/真人证据齐全；QPSK另作条件扩展 |

4096点/60MSPS仅约68.27微秒，诊断只描述采集窗口。脉冲不在窗口内可能漏检，不能称持续监测或全时环境正常。受控IQ叠加经有线回环是复现条件，不代替外部干扰源空口测试。

首轮候选档仅改变峰值码：P0=60、P1=40，其余BPSK/RF参数固定。第二档须先正常同步/BER/关闭验收，再做异常工况成对收益验证。没有收益时交付观察/停止建议，档位优化演示记未验收；不承诺降低幅度能抗干扰，不把码值称绝对射频功率。

成对实验固定目标BPSK分量与异常分量独立叠加，候选码值只改变目标信号，异常码值不随之缩放，不做叠加后的整体归一化。核心S3必交的是建议/拒绝与人工安全流程；没有收益不阻塞核心观察/停止演示，但不能展示已实现档位优化。
