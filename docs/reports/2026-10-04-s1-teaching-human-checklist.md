# S1 实体屏测试：从准备到结束，按顺序操作

**最新验收结论：S1已通过。** 用户确认捕获间隔体验不卡顿，并明确取消为体验专门计时；第8步为可选历史步骤，无需执行。精确时延仍记NOT_MEASURED，不冒充实测、不阻塞S2。关闭收据：`evidence/rf-teaching/s1/closure-2026-10-04/receipt.json`。下方此前“只需第8步”等状态保留为历史，以本段为准。

本流程针对已安装的 S1 发布 `c3bf915c544563324778d1c879b38e3a`。最新状态：机器验收已通过，11张实体屏照片和用户补充文字确认闭合本轮真人功能；20次触摸计时仍未测。已确认的功能无需重做，当前只需准备正常会话后执行第8步计时。详细结果见 [照片复核报告](2026-10-04-s1-human-photo-review.md)。下方第0～10步保留为完整操作流程，供初次测试或需要复验时使用。此前 S0 的五项测试已有文字确认，本文件不把它们当作尚未完成的前置条件。

**第一次请从第0步开始。先做完第0～3步，确认正常回环成功，再继续第4～10步。** 沿用现有 TX1→RX1 接线，无需重新接线或上传视频。每个编号是一项测试，编号下面的序号是点击顺序。

全程顺序：安全起点 → 填配置 → 建立会话并加载 → 三次正常回环 → 关闭参考 → 保存与31秒过期 → 域外设置与恢复 → 取消 → 20次计时 → 停止/解除 → OFF负控与结束。

## 先认清三个操作

| 操作 | 做什么 | 在哪里用 |
|---|---|---|
| 加载调制 | 将调制数据加载，供后面的有限回环使用；单独加载不会开始持续发射 | 第2步，或会话恢复时 |
| 回环捕获 → 确认回环 | 进行一次有限的 TX1→RX1 回环，并生成一帧新结果 | 正常回环、关闭参考、域外测试、计时 |
| 捕获快照 | 只接收一帧，不启动回环发射 | 第10步 OFF负控 |

本流程不需要点击“发射”。“已武装”表示会话已获准操作，不表示正在持续发射。

数字输入框修改后，点弹出键盘里的“确认参数”。布防弹窗里的“确认”和回环弹窗里的“确认回环”是另外两个按钮。

## 第0步：建立安全起点

1. 确认当前设备为 **AD9361**，TX1→RX1 接线仍在位。
2. 若当前有操作正在进行，先等它完成，然后点屏幕底栏 **停止 AD9361**，等停止结果返回。
3. 点左侧 **发射**，再点顶部 **RF参数**。
4. 如果当前仍是已武装，点 **解除**，等解除完成。如果已经未布防，解除不可用，可以跳过这次点击。
5. 点左侧 **接收 → 概览**，查看状态。

**应看到：** 未布防/未武装，`TX选择：否`，`RX布防：否`。无分析结果时，这两项在概览页的 PL快照区域。若找不到字段，先记“未看到”，不要把未看到当成关闭成功。

**记录：** 起始未布防、TX关闭、RX关闭是否都确认。

## 第1步：一次性填好教学配置

1. 点 **接收 → 星座 → 填入教学配置**，只点一次。它只填配置草稿，并清除旧结果和加载凭据；此时没有星座或BER是正常的。
2. 点 **接收 → 采样**，核对抽取为 **D1**、点数为 **4096**。
3. 点 **接收 → 解调**，核对 **BPSK、预期符号率3000000、RECT**。
4. 如果按钮显示 **PRBS7参考: 关闭**，点一下，让它变成 **PRBS7参考: 开启**。核对 **参考种子为1**。
5. 点 **发射 → RF参数**，核对下表。需要修改数字时，输入后点“确认参数”。

| 参数 | 本次固定值 |
|---|---|
| 采样率 | 60000000 Hz（60 MHz） |
| RX/TX本振 | 80000000 Hz（80 MHz） |
| RX/TX带宽 | 30000000 Hz（30 MHz） |
| 内部发射衰减 | 40000 mdB（40 dB） |
| PHY | 0 |
| 延迟开关 | 1 |
| 延迟档位 | 29 |

6. 点 **接收 → 星座 → 高级发射工具**，进入数字调制工具。核对 **BPSK、符号率3000000、RECT、PRBS7种子1、峰值码60**。暂时不加载。
7. 返回 **发射 → RF参数**，准备第2步。

**应看到：** 接收参考已开启，收发参数与上述值一致。数字调制工具里的“理想发射示意”是发射示意图，本次真实星座要到“接收 → 星座”查看。

后续恢复会话时不要再次点“填入教学配置”：它会将接收参考恢复为关闭，并使加载凭据失效。

## 第2步：建立会话，再加载调制

按下面顺序操作，每个按钮都等完成后再点下一个：

1. 在 **发射 → RF参数** 点 **布防**。
2. 出现确认提示后，点 **确认**，等布防成功。
3. 点 **初始化**，等初始化成功。
4. 点 **配置**，等配置成功。
5. 点 **接收 → 星座 → 高级发射工具**，点 **加载调制**，等加载成功。此时不要点“发射”。
6. 点 **接收 → 概览**，核对 **READY、已武装、TX选择：否**。
7. 点 **星座**，进入第3步。

**应看到：** 回环捕获可以操作，尚未捕获时无当前真实星座也正常。

### 中途过期或回环按钮不可用时，从这里恢复

会话闲置约30秒会过期；阅读屏幕或切换页面不能保证续期。第5步故意等待31秒后，也可能需要恢复。

如果出现未武装、OFFLINE、加载失效或“回环捕获”不可用，先记录当时提示，然后依次执行：

1. 底栏 **停止 AD9361**，等完成。
2. **发射 → RF参数 → 解除**，仍已武装时才点；已解除则跳过。
3. **布防 → 确认 → 初始化 → 配置**，各项都等成功。
4. **接收 → 星座 → 高级发射工具 → 加载调制**，等成功。
5. 返回 **接收 → 星座**，继续原来那一项测试。

保持当前接收参数，不重新填教学配置。恢复操作会使旧结果失效；恢复后必须重新捕获。出现削顶、超时、FAULT、关闭未确认或异常自动发射时，不按普通过期处理，按文末异常说明记录并停止测试。

## 第3步：连续取得三帧正常回环结果

每一帧都按下面顺序走一遍，一共三遍：

1. 在 **接收 → 星座** 点 **回环捕获**。
2. 出现提示后，点 **确认回环**，等新结果显示。
3. 在星座页记录 **快照ID、显示点、有效符号、错误/比特**。
4. 点 **解调**，记录这一帧的 **载波同步、定时同步、参考同步、BER**。
5. 返回 **星座**，再开始下一帧。不要在三帧之间停止、解除或修改参数。

**通过条件：**

- 三个快照ID彼此不同。
- 星座页标明真实接收，显示点最多128；本次固定配置的有效符号预期为201。
- 解调页载波、定时、参考均同步；错误/比特的比特数预期为138，BER不超过1%。机器验收为0/138，但请照实填写实体屏结果。
- 128是绘图点数、201是有效符号数、138是BER统计比特数，它们不用相等。

**记录：** 三帧各自的ID和结果。若第3步不能成功，先报告卡在第几个点击和屏幕原文，不继续后面的负控。

## 第4步：关闭参考，新帧仍有星座但没有BER

1. 第3步结束后，在 **解调** 页点 **PRBS7参考: 开启**，将它变为 **关闭**。
2. 先看旧BER是否立即失效，再到 **星座** 看旧星座是否失效；此时不要先捕获。
3. 在 **星座** 页点 **回环捕获 → 确认回环**，等新帧显示。
4. 查看星座页：应有真实星座，最多128点、预期201有效符号，**错误/比特为 --**。
5. 点 **解调**：参考应显示未提供，**BER为 -- 或无有效值**，不能沿用之前的0/138。
6. 将 **PRBS7参考** 再开启，核对种子1。
7. 返回 **星座**，重新回环捕获一帧，确认正常星座和BER恢复，供第5步保存。

**记录：** 关闭参考后旧值失效是否及时；新帧是否有星座、无BER；重新开启后的新帧是否恢复。

## 第5步：保存当前实验，再测试31秒过期与历史保存

### 5A：保存一帧当前有效结果

1. 在 **星座** 页，确认第4步最后一帧仍有效。若已过期，恢复会话并重新捕获。
2. 记下当前 **快照ID**。
3. 点 **保存当前实验**，等保存完成。
4. 看保存状态。实际界面文字是 **正在保存 → 历史记录已保存**；即使点的是“保存当前实验”，成功提示也是“历史记录已保存”。这不表示当前帧立即过期。
5. 核对快照ID没有变化；保存不应自动采集一帧，也不应自动开始发射。

### 5B：新捕获一帧，专门等待过期

1. 保存完成后，**再进行一次正常回环捕获**。
2. 从这次新结果显示时开始计时，记下它的ID。
3. **等待至少31秒**。等待期间不捕获、不改参数、不停止、不加载；不需要持续点击屏幕。
4. 等待结束后查看 **星座**：当前点应消失，**保存当前实验** 应不可用。
5. 查看 **解调**：旧BER应失效，不能继续显示为当前有效结果。
6. 返回 **星座**，点 **另存历史实验**，等显示 **历史记录已保存**。
7. 历史保存后，当前星座和BER仍应无效；不能把历史结果重新显示成当前有效结果。
8. 按第2步下面的“中途恢复”流程重建会话并加载，然后重新正常回环捕获，确认能继续测试。

**记录：** 当前保存成功/失败、等待秒数、过期清点/清BER、历史保存成功/失败、恢复后能否取得新帧。

板端文件读取和完整性核对由开发端后续完成。你在屏幕上测试时不用运行Python命令，也不用寻找板端文件目录；“按钮保存成功”和“文件完整性核对”分别记录。

## 第6步：只改接收预期，测试域外拒绝，再恢复

本步骤只修改 **接收 → 解调** 的预期参数。不要进入高级发射工具改TX参数。

### 6A：预期符号率改成2M

1. 在 **接收 → 解调**，把 **预期符号率** 改为 **2000000**，点键盘里的 **确认参数**。保持BPSK、RECT、参考开启、种子1。
2. 到 **星座** 页重新 **回环捕获 → 确认回环**。
3. 看新结果：应无有效星座点；到 **解调** 页应无有效BER，并有不支持/域外等拒绝原因。记录原文。

### 6B：恢复3M，再把接收成形改成RRC

1. 回到 **解调**，把预期符号率恢复为 **3000000**，确认参数，再将接收成形切换为 **RRC**。
2. 到 **星座** 页重新 **回环捕获 → 确认回环**。
3. 应无有效星座和BER，并有拒绝原因。记录原文。

### 6C：全部恢复，验证新帧正常

1. 回到 **解调**，恢复 **BPSK、3000000、RECT、参考开启、种子1**。
2. 到 **星座** 页重新 **回环捕获 → 确认回环**。
3. 应重新有真实星座，解调同步和BER恢复。仅修改回正确参数，不应把旧帧恢复成有效结果。

**记录：** 2M结果、RRC结果、恢复后新帧结果。域外拒绝和真实无信号是不同测试；真实无发射负控在第10步进行。

## 第7步：取消回环提示，不产生新采集

1. 在 **星座** 页记下当前快照ID。
2. 点 **回环捕获**，等确认提示出现。
3. 点 **取消回环**，不要点确认回环。
4. 核对没有新快照ID，也没有执行回环发射。原来尚未过期的帧可以继续显示；本项不要求取消时清空旧帧。

**记录：** 取消前后ID是否相同、有无新采集。

“取消回环”和采集进行中的“取消捕获”是两个测试。如果一次采集太快，来不及点击“取消捕获”，就记 **未触发**，不要记通过。无需为此反复快速点击。

## 第8步：20次实体触摸到新结果的计时

此项可单独报告未测；未测时继续第9～10步结束会话。未测的计时项目仍保留待验收。

1. 确认正常配置已恢复：BPSK、3M、RECT、参考开启、种子1；会话已建立且调制已加载。
2. 进入 **星座**，记住旧ID，点 **回环捕获**。
3. **t0：手指从“确认回环”按钮抬起的时刻。**
4. **t1：新快照ID和这帧结果首次同时出现在屏幕上的时刻。** 不能把旧星座当作新结果。
5. 记录 `t1 - t0`、新ID、是否成功。
6. 重复20次。中途会话过期可按恢复流程处理，但恢复会话的时间不计入单次捕获耗时；失败和异常慢的测量不能删掉。

可用你自己的录像逐帧读时刻，录像无需上传。请记录帧率或计时精度。若只用秒表或目测，注明“人工粗测”，不要填写没有测量依据的精确毫秒数。

**记录格式：** `序号 | 新快照ID | 耗时ms或s | 成功/失败 | 备注`，再附计时方法。后台ARM计算耗时不替代此项实体触摸测试。

## 第9步：停止清结果，然后解除

1. 先保证屏幕上有一帧当前有效的正常结果。若已过期，恢复会话并新捕获一帧，以便观察停止是否清除结果。
2. 点底栏 **停止 AD9361**，等停止完成。
3. 看 **星座**：当前点应失效；看 **解调**：当前BER应失效。
4. 点 **发射 → RF参数 → 解除**，等解除完成。若已自动解除，记录实际情况。
5. 点 **接收 → 概览**，核对 **未布防/未武装、TX选择：否、RX布防：否**。

**记录：** 停止清点、停止清BER、解除结果、两路关闭状态。停止会使调制加载凭据失效，不能直接再次回环。

## 第10步：不加载、不发射，做OFF负控并结束

这一步故意让接收端采到“没有本机回环发射”的结果。

1. 核对 **接收 → 解调** 仍是 **BPSK、3000000、RECT、参考开启、种子1**。
2. 到 **发射 → RF参数**，依次 **布防 → 确认 → 初始化 → 配置**，各项等成功。
3. **到这里就停止配置。不要加载调制，不要点发射，也不要点回环捕获。**
4. 到 **接收 → 概览**，点普通的 **捕获快照**，等采集结果。此操作不需要“确认回环”。
5. 到 **星座** 看结果：应无有效同步星座。
6. 到 **解调** 看结果：应无参考同步、无有效BER。具体拒绝原因可能是无能量或失步，照实记录。
7. 最后点底栏 **停止 AD9361**，等完成。
8. 到 **发射 → RF参数 → 解除**，等完成；已自动解除则记录。
9. 到 **接收 → 概览**，最终确认 **未布防/未武装、TX选择：否、RX布防：否**。

**记录：** OFF无星座、无参考同步、无BER，以及最终三项关闭状态。到此本轮屏幕测试结束。

## 异常时怎么记录

任何削顶、超时、FAULT、关闭未确认或异常自动发射：暂停后续测试，执行 **停止 → 解除**，记录“第几步、第几个点击、屏幕提示原文、能否停止/解除”。不要仅写“失败”。无需上传视频；文字可以先定位，已有照片也可以保留。
