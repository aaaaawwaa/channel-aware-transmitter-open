# Zynq + AD9361 通信教学平台总体路线

> **规划文档。** 本文件把用户 2026-10-13 提供的作品简介作为最终目标，按可独立验证的子项目拆解。每阶段进入实施前须另写精确接口、测试与板卡门禁；本文件不授权直接上板发射、安装或加载 Overlay。

2026-10-13 执行重心已切到 `final_prj`；原工程的 DeepSeek Harness 工作建议停在当前审核门。详细文件与首批执行顺序见 [final_prj 实施计划](2026-10-13-final-prj-implementation-plan.md) 和 [切换判断](../../reports/2026-10-13-final-prj-focus-decision.md)。

**目标：** 形成以 Zynq SoC 与 AD9361 为核心，覆盖多制式信号生成、射频收发、接收分析、环境感知和受约束档位决策的五寸触摸屏实验平台，并以数字回环、有线模拟回环和真实采集数据逐层证明。

**推荐路线：RF 纵向闭环扩展。** 沿用已有 `rf_overlay/` 与 `pynq_overlay/sw/` 的 RF 接收/界面/发布链，从已验收的有限 BPSK 域逐项扩展到 QPSK、QAM、RRC/EVM 和决策。AWG/ACM2108 保持独立参考与辅助信号源；先统一作品入口和证据口径，再考虑共用 GUI 或数据接口。

## 方案取舍

| 方案 | 优点 | 代价 / 判断 |
|---|---|---|
| A. 沿现有 RF 链纵向扩展（推荐） | 复用真实 IQ、BPSK、触摸屏、CNN、发布与安全门禁；每阶段可独立验收 | 必须补多制式接收、EVM 和 S3 决策，不能用已有 AWG 功能替代 |
| B. 先把 AWG、PYNQ、RF 合成单一位流和控制平面 | 名称和入口看起来统一 | 现有三条流水线产物不兼容；集成风险高，会延迟可验证 RF 闭环 |
| C. 从空工程重写 RF 平台 | 架构最自由 | 放弃现有板端与实测基线，硬件/驱动风险最大；缺少必要收益 |

## 产品边界与接口

1. **RF 主路径**：`rf_overlay/rtl/` 负责 AD9361 样点传输、有限采集和经证明需要的实时 PL 功能；板载 Linux/PS 负责射频配置、受控会话、快照分析、轻量模型与决策策略。涉及“PL 实时处理”的对外表述须列出实际 RTL 模块、时钟、吞吐与测得时延。
2. **能力状态**：每个调制模式、采样率、滤波档、接收算法和模型都有 `SUPPORTED / UNSUPPORTED / INVALID / STALE` 等明确状态与版本。UI 只显示与当前同帧、同配置、同发布对应的结果。
3. **证据对象**：一次实验绑定发布 ID、bit/HWH/daemon/模型与算法摘要、配置、真实读回、原始 IQ、时间与会话身份、分析结果、人工操作和安全关闭结果。离线回放必须在相同 IQ 上复现判决与图表。
4. **安全控制**：唯一板端控制者；候选档只能从独立实验证明的白名单中选择。模型分数不直接触发 TX；建议、人工确认、重新校验、加载与关闭分离。失联、削顶、过期、错版本、未知环境或关闭读回不完整时拒绝档位变更并保留未知结局。
5. **项目入口**：新副本文档以本简介为产品目标。保留 AWG、PYNQ、RF 的独立构建和位流，发布文档明确“本作品 RF 路径”和“辅助 AWG 路径”，避免把不同硬件链路的测试相加。

## 阶段与验收门

### P0 — 冻结基线和需求追踪

- 固定本副本的源码快照、现有 b82 资格/安装事实及所有历史证据的原路径；把本审查表转成“需求 → 模块 → 测试 → 原始证据 → 板端版本”的可更新矩阵。
- 建立 RF 主入口和能力表；澄清“接收数据查看”首版展示原始 IQ、判决符号与比特，协议载荷/CRC 属后续独立合同。
- 对关键源码 `rf_overlay/{rtl,sw}`、`pynq_overlay/sw/{rf_iq_signal,rf_bpsk_receiver,rf_rx_analysis,rf_rx_constellation,rf_cnn_runtime,ui_*}` 建立准确版本/测试基线；先处理 copied worktree 与历史提交差异，不让未提交快照伪装成可重建发布。
- **门禁**：新分支可重建、全部已有测试基线记录、每条简介要求有责任模块与验收状态。

### P1 — 关闭现有 BPSK 与环境诊断基础门

- 完成当前 HEADROOM 板端 runner 的运行包、持久派发、异常读回与最终摘要独立复审；按既有人工接线/一次性授权门执行最多五次 46 dB 有限研究。
- 仅在研究支持稳定实验域时，完成独立 TRAIN/VAL、开发复验、S2 正式 108 物理+12 离线和实体屏验收；失败时保留原始失败帧并回到单变量诊断。
- 保持 BPSK3M RECT、同帧星座、频谱、BER、实验记录和触摸停止/解除的现有能力不退化。
- **门禁**：真实读回安全、原始 IQ/分析可回放、S2 成败有冻结收据；此前不把环境识别称作作品完成。

### P2 — 多制式射频发射与 PL/PS 分工实证

- 对 BPSK、QPSK、QAM16、QAM64、RECT/RRC 建立逐模式 TX 合同：比特映射、PRBS/用户数据、RRC 系数与群延迟、量化、AD9361 实际采样率、频谱与幅度范围。
- 先复用 PS 生成样点和现有 PL 传输；用吞吐、CPU、内存、持续时间实测决定哪些实时处理必须迁入 PL，再单独实现 RTL 与时序/网表/物理验收。绝不把 AWG 的 `src/rtl/iq_digital_mod` 直接记作 AD9361 PL 成果。
- **门禁**：每模式数字回环、TX1→RX1 有线采集、谱形与误码参考均有独立证据；PL 职责和资源/时序有板上数据。

### P3 — 多制式接收、指标与数据查看

- 以现有不可变 RX IQ 帧为输入，先扩 QPSK 载波/定时/相位歧义和符号判决，再做 QAM16/64 的均衡、归一化、判决及拒绝域；RECT 与 RRC 匹配分别验收。每一步独立参考，不使用 TX 标签或 CNN 类别代替真实解调。
- 明确定义参考对齐、BER 分子/分母、EVM 参考点与归一化、削顶/失步拒绝规则；无可验证参考时 UI 显示不可用。区分“模型识别的调制类别”和“接收机同步成功”。
- 五寸屏展示同帧时域、频谱、星座、EVM、BER、IQ/符号/比特有界预览；导出原始数据与分析元数据。连续接收和协议帧作为后续单独范围，不用有限快照暗示已支持。
- **门禁**：合成注错、数字回环、不同会话有线真实 IQ 的主机/ARM 一致性；各制式独立测量精度、拒绝率和计算时延，真人触摸路径验收。

### P4 — 环境识别与可信度

- 将窄带、周期脉冲、正常、复合/域外/无信号等状态限制在已声明采样窗口；明确短快照漏检条件。特征包含时间峰值/脉冲统计、频域窄带结构、削顶及基础接收质量；模型与规则输出来源、分数、质量状态和拒绝原因。
- 将训练/验证/测试按采集会话和物理配置分组，独立保留真实测试集。模型分数只有经过校准与可靠性检验后才称“可信度”；否则标为未校准分数并以保守规则拒绝。
- **门禁**：冻结类别与负控、逐类混淆矩阵、未知/过期拒绝、真实有线数据和 ARM 性能收据；空口泛化须另测，不由有线结果推断。

### P5 — 受约束档位选择与人工接管

- 建立候选发射档位表：每档有合法 RF 参数、真实读回、接收收益/代价证据、有效域和发布摘要。现有 P0/P1 峰值码仅为待资格候选，不能先称优化成功。
- 策略以当前同帧诊断、置信条件、档位资格、安全状态和人工授权生成“保持 / 停止 / 候选变更 / 无法判断”及解释；策略本身无硬件 IO。
- 人工确认后仍走已有唯一控制链重新校验与加载，记录前后读回；取消、失联、异常和无收益保持/安全关闭。默认不开放自动发射或自动换档。
- P5b 是简介所述智能选档的最终验收门：在人工确认链验收之后，只对白名单档位开放受约束自动执行，并逐项证明人工抢占、看门狗、独立读回及异常回退。默认关闭；人工建议通过不等于 P5b 获得资格，未通过则作品整体不能按简介宣称完成。
- **门禁**：候选档各自独立验收，成对干扰收益测试不挑选成功帧，人工确认/拒绝/失效/回退实体屏和板端验证通过。无收益时只交付观察/停止建议，不宣传档位改善。

### P6 — 作品级集成与可复现交付

- 固定数字回环 → 有线模拟回环 → 多会话真实采集的逐层证据链；覆盖正常、窄带、脉冲、无法判断、错版本、削顶、断线和关闭不确定等场景。
- 交付单一操作指南、接线图、版本清单、屏幕流程、原始 IQ 与重放工具、性能/资源报告和明确限制。最终简介逐句链接到通过的收据；未通过项目保留“拟支持”。
- **门禁**：完整板卡发布身份、安全关闭、现场触摸与长时间运行记录一致；独立复审后才对外使用“已实现”表述。

## 近期执行顺序

1. 在本副本做 P0 基线与需求追踪；核验复制件和所有关键依赖。历史 `evidence/` 保留在原工程中，不以规划副本里的报告替代原始收据。
2. 并行写 P2 发射模式矩阵、P3 接收指标定义的设计稿，但板端执行仍遵循 P1 的 HEADROOM 与 S2 门禁。
3. P1 稳定后，按 QPSK 接收 → RRC 接收 → QAM16 → QAM64 → EVM 的依赖顺序推进；各项单独封存验收，不用单一“全部调制通过”概括。
4. 环境可信度和 P5 档位决策建立在已冻结的接收与物理证据上，最后再做 P6 作品级整合。

**当前判断：** 本简介可作为 `final_prj` 的目标规格；现有工程不能按该简介直接宣布完成。特别是多制式接收、EVM 和已验证档位选择是实质新增研发，不属于简单改写文案。
