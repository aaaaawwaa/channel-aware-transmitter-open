## 本轮验证发现

复现数据和现状截图位于 `evidence/2026-10-01-session-ui-audit/`。

1. `rf_tx_waveform.py::build_square` 使用整周期编号奇偶性决定高低电平，cycles=32 时 FFT 主峰为 bin16；cycles=1 为整帧恒定正电平。必须改为每周期内部相位判定。
2. `build_multitone` 将两路直接相加。两路 amplitude=2047、cycles=32/16 时峰值 ±3593，384/1024 点越过 [-2048,2047]。`rf_sample_reader.v` 取低 12 位，不会自动饱和，越界有符号翻转风险。
3. 双音第二音周期框 y294..333 与说明 y306..324 交叠；第二音幅度框 y342..381 与两行说明交叠。Chirp 与 Noise 同样受影响，现状 PNG 已核看。
4. 波形类型仅显示 1..8 数字编号；CW/Noise 仍展示无意义的周期输入。`rf_tone_frequency_hz()` 仅按周期计算，不能准确表达 CW、Noise、双音或 Chirp。
5. LO 输入允许从 1Hz 起、采样率允许到 INT32_MAX，和 session 记录的项目范围、80MSPS 失败不一致；1R1T 可初始化但当前 load 路径明确要求 PHY=0。UI 应在操作前解释限制。
6. 现有针对性回归 29 passed；扩展波形用例仅验证元数据及 payload 长度，未证明频率、幅度或全部波形子状态的布局正确。
7. 触摸延迟已离线复现：`UiView.render` 先 `_poll_input()` 重放旧点，再 `cursor.read()` 读取本帧触摸。按下/抬起分别在第1/2帧采到，RF子页直到第3帧才切换；常规主循环 `UI_PERIOD=0.1`、`POLL=0.05`，至少额外增加一帧输入延迟。具体板上总延迟尚未实测。RF控制已有后台worker，不能把这个已复现的问题归因于网络操作。

## 方案比较与推荐

推荐采用「统一操作 + 按目标设备选择后端」。依次实施A/B/C三个包，首轮修复明确交互问题并提供常见波形兼容，随后完成AD9361数字调制和损伤兼容。复用当前PL与协议，区别仅在信号计划与执行路径。短文件I/Q和长流播放不是本次核心需求，另列后续。

另一个选择是只改外观，成本低但保留错误波形与缺失 Pulse；第三个选择是同步改 RTL 实现双 TX 独立、长流式播放，范围大且要重建位流、执行网表门禁。本草案推荐第一种。

## 首轮范围与布局

对象是 800×480 的板载触摸 UI。保留一级导航与现有唯一 Overlay 所有者。工作区顶部新增固定二段按钮「ACM2108 / AD9361」，在发射和数字调制/信道损伤工具页可见；顶栏显示当前操作对象。RF 参数和 RF 波形都在发射页，避免“波形”含义混淆。

目标选择保存于纯UI模型，只改变编辑/命令路由，不隐式初始化、加载、启停或切换硬件源。ACM2108与AD9361分别保存波形、调制、损伤草稿和已应用状态。离线也可切换查看参数与能力。未完成控制事务期间禁用切换，STOP仍可排队；切换目标会取消未发送的本地确认。稳态输出期间允许切换查看另一设备，常驻显示各设备运行状态，并保留针对活动RF/数字调制的明确停止入口；运行目标仍锁定其受限参数编辑。ACM2108普通AWG的连续输出不冒充DIGMOD运行状态，也不因没有全局停DAC命令而永久锁住切换。切换后不恢复、重启或停止任何输出。仅模型状态不足以证明硬件已停止时显示未知，拦截受影响的硬件操作，不能把目标选择当成设备停止。

所有硬件动作在计划生成时冻结目标ID、草稿和参数，异步完成结果也带目标ID，不能因用户随后切页将ACM2108结果落进AD9361模型。现有ACM2108数字调制状态判据保持；RF状态继续采用新鲜遥测证明。

AD9361 内使用「射频参数 / 波形设置 / 发射控制」三个子页，ACM2108使用原有波形/通道功能。设备按钮与子页标签各占独立一行，按剩余工作区重新分配卡片高度；复杂字段分页，所有内容在标签下，不再占用字段或状态标题位置。

频率键盘提供 Hz/kHz/MHz；LO再提供GHz，符号率提供Sym/s、kSym/s、MSym/s。支持小数点和编辑当前单位数值，例如LO输入100MHz、采样率60MHz、AWG频率1kHz。用十进制定点/Decimal乘单位倍率，只在结果为整数Hz且范围合法时提交；不使用二进制浮点取整。切换单位等值换算，不重置用户数值；取消、错误、仅选择单位均不发硬件命令。清空保持未填，拒绝多个小数点、负频率、超范围和无法表示为整数Hz的精度。键盘确认仍只提交草稿。

触摸在每次输入tick先采样GT911一次，再将相同点交给控件和准星，移除上一帧重放。绘制前重新取得页面和显隐，切页事件当帧呈现新页；不以每帧整屏重绘换响应。将输入调度与0.1秒状态刷新解耦，目标20ms输入tick，事件改变时立即画；硬件按钮、状态采集和关机保留各自周期，耗时网络/诊断不进入触摸路径。先测冷/热渲染、触摸读取、命中与flush，再确认板卡能否达到输入节拍；离线证明无多余一帧延迟，板上以抬起到可见反馈P95≤100ms作为验收目标，未量测不称达标。

波形设置提供可读名称按钮：正弦、CW载波、方波、三角、锯齿、脉冲、双音、Chirp、噪声。按钮与参数分区；较多参数用下一页/上一页切换，避免压缩触控框。保留高级周期/码值输入用于原有验收流程，普通模式显示基带频率 Hz、幅度 %、脉冲占空比 %。CW不显示频率/周期，Noise显示种子，双音显示两组频率/幅度，Chirp显示起止频率。没有测量依据时仅标示合成示意，不显示校准电压或绝对功率。

发射控制显示完整准备流程：未布防 → 已布防 → 已初始化 → 已配置 → 已加载 → 实际发射。每一步显示可执行动作和缺失原因，不能将请求排队当成成功。底栏隐藏 AWG「应用设置」「启动数字调制」，替换为 RF 操作状态与可达 STOP；确认和取消与 STOP 不重叠。停止、解除在 RF 子页和确认界面始终可达。错误显示中文操作说明并保留原 daemon 错误码。

中文字号至少14px，主要触控目标至少40px高，长内容换行或分页，不覆盖邻居；保留顶栏、导航和底栏区域。板端字体与桌面字体不同，离线截图不代替实体屏可读性验收。

## 参数与波形契约

固定1024点和实际已应用采样率 Fs；整周期模式的分辨率为 Fs/1024。以60MSPS为例，频率步进58593.75Hz；1MHz最近可表达996093.75Hz。UI同时显示请求值、有效值和误差；小于一步进、超Nyquist或取整到无效周期时明确拒绝，不悄悄改成CW或低频。有效 cycles 为1..511。频率单位指基带，RF频率说明按 waveform 区分：CW在LO，实数正弦为LO±fbb；复杂波形展示基带带宽/频率范围，不承诺单一载频。

幅度百分比映射为round(2047*pct/100)，0%生成零IQ，范围0..100%。码值兼容保持整数范围；模型、生成器和UI均接受一致的零幅度语义，不将零幅度标成RF停机。Pulse采用双极性 ±amplitude，duty=0全负、100全正；中间值按每周期相位判定。Square固定50%占空比。有限采样下实际占空比可量化，显示有效值，不声称所有周期都恰好达到请求百分比。

双音首先拒绝两路峰值和大于2047的配置，并提供明确“请降低两路幅度”提示；不自动归一化或截断用户幅度。全部输出I/Q逐点落在12位有符号范围。Chirp周期回放边界与宽带特征明确说明，不能把当前chirp当成平滑无限连续扫频。Noise为可复现伪随机幅度序列，不宣称是PRBS/PN数字符号源。

项目LO UI范围为70MHz..2.1GHz，2.1GHz为工程约束；2.1GHz边界物理成功尚待专项证据。采样率上限先按61440000Hz拦截，非零下限沿用协议，不承诺所有下限值均能在当前驱动初始化；真正支持的速率由daemon实际结果决定。60MSPS为已有记录的验收值，不自动填写RF参数。当前数据加载要求2R2T，模式选择显示「2R2T（当前TX可用）」与「1R1T（TX暂未验收）」；1R1T仍可显式配置用于后续诊断，但load前给出明确门禁原因。RX/TX带宽使用既有校验，进一步设备范围只在拿到驱动证据后调整。

## 状态、所有权与集成边界

保留 draft/applied/observed、后台长操作、参数快照与网络事务锁、load后持久连接。编辑波形/RF参数取消待确认和已加载准备；执行中/实际发射时锁定编辑。保持30秒成功控制请求续期、只读轮询不续期，不自动续期、布防或重新启动；UI注明规则，只有可靠的控制时间证据才能新增倒计时。

各文件职责：`rf_tx_waveform.py`负责纯IQ生成与范围校验；`ui_model.py`负责目标选择、各目标草稿、能力、输入映射、准备状态与门禁；`ui_view.py`负责字段可见性、单位键盘、名称选择、版式和触摸；worker/client维持既有传输契约；`pynq_status.py`按计划target路由ACM2108命令或RF后台任务，并维护输入调度。纯单位转换可拆小模块，数字调制/损伤生成在C包独立纯函数模块中实现。没有新增独立硬件写通路。

统一工具页根据目标能力展示同一组概念：调制方式、符号率、源、成形、噪声、抽头。ACM2108沿用其真实寄存器路径；AD9361在C包将BPSK/QPSK/QAM16/QAM64、PRBS7、RECT/RRC与有限长度复数FIR/噪声预计算为IQ，再经既有tx.load/start执行。必须处理1024/4096点容量、每符号采样数、重复帧接缝与峰值，不能将10Sym/s或USER长流宣布为同等支持。未完成的功能明确禁用并给原因，不能误发ACM2108的SET命令到RF。最终交付必须以能力矩阵标出两个目标实测支持范围与差异，并有每个共用操作的路由负控。
