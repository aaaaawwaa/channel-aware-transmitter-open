# 任意波形发生器(AC820 + ACM2108 高速 DAC)设计文档

- 日期:2026-08-11
- 板卡:芯路恒 AC820(xc7z020clg484-2,Zynq-7020)
- 模块:小梅哥 ACM2108(双通道 8bit ADC MS9280 + 双通道 8bit DAC MS9708,±5V 模拟范围,LVCMOS33)
- 工具:Vivado 2018.3 + `cli-anything-vivado` CLI
- 方式:纯 PL,零 IP,50MHz 系统时钟直驱
- 替代:本设计取代 `2026-08-11-awg-es8388-design.md`(ES8388 音频输出版),旧 spec 保留备查

## 1. 目标

用 ACM2108 模块的 **MS9708 DAC(8bit 并行,125MSPS)** 实现高速任意波形发生器:

- 4 种波形:正弦 / 方波 / 三角 / 锯齿(拨码 SW0~SW1 选择)
- 频率 10Hz~1MHz,10Hz 步进,S1 加 / S2 减,长按加速
- 双通道 DAC0/DAC1 同步输出相同波形
- LED 显示:LED0~1 波形类型,LED2~7 频率粗刻度
- ADC(MS9280)不使用;整机纯 PL,不涉及 ARM/SDK

## 2. 硬件上下文

### 2.1 ACM2108 模块接口(40pin,直接对插 AC820 GPIO0)

| 信号 | 说明 |
|------|------|
| DAC0 DB[7:0] | 通道 0 DAC 数据(MS9708,8bit 并行,上升沿锁存) |
| DACLK0 | 通道 0 DAC 时钟 |
| DAC1 DB[7:0] | 通道 1 DAC 数据 |
| DACLK1 | 通道 1 DAC 时钟 |
| ADC0 DB[7:0] / ADCLK0 | 通道 0 ADC(MS9280,本设计不使用) |
| ADC1 DB[7:0] / ADCLK1 | 通道 1 ADC(不使用) |

- 模块供电 +5V/GND,接口电平 LVCMOS33
- AC820 GPIO0 为 40pin IDC3-40(36 IO + 5V + 3.3V + 2 GND),模块直接对插、引脚一一对应
- **待办:AC820 侧管脚信息表**(官方帖附件)用于写 XDC;未取得前按直接对插假设分配,硬件核对一次

### 2.2 板载资源

| 信号 | 引脚 | 说明 |
|------|------|------|
| FPGA_GCLK | Y9 | 50MHz,`create_clock -period 20` |
| S1 / S2 | H18 / H19 | 按键,按下低 |
| SW0~SW1 | G21 / G20 | 波形选择,上拨=1 |
| LED0~7 | P20 P21 R20 R21 R19 T19 T16 T17 | 高电平点亮 |
| GPIO0 | 见 2.1 | 模块接口 |

全部 IOSTANDARD LVCMOS33。

## 4. 参数与数据流

- **采样率**:50MHz,相位累加器每个时钟周期累加一次 fword
- **fword 公式**:`fword = freq×85 + (freq×9)/10`
  - 精确值 2^32/5e7 = 85.89934592;85 + 9/10 = 85.9,误差 0.0008%(1MHz 时差 654 LSB,8bit 量化下无感知)
  - 10Hz → 859;1kHz → 85,900;1MHz → 85,900,000(< 2^32 ✓,20bit×85 乘法不溢出)
- **正弦 ROM**:256 点 × 8bit 有符号(±127),`dds_core` 取相位累加器高 8 位查表
- **其他波形**(8bit):方波 = 相位 MSB(±127);三角 = 8bit 折返;锯齿 = 高 8 位(映射 ±127)
- **DAC 时序**(MS9708 上升沿锁存):数据在 posedge clk 更新;`DACLK = ~clk` 的寄存器输出,其上升沿落在数据更新后 10ns(半周期),建立时间充足;DAC0/DAC1 共用同一数据与时钟,同步锁存
- **数据格式(重要)**:ACM2108 模块 DAC 期望**偏移二进制**(0..255,128 = 中点);DDS 输出二进制补码(-128..+127),`dac_driver` 内做 `sample ^ 8'h80` 转换(实测:补码直出会导致正弦/三角 V 形错位、方波归零,已用偏移二进制修复)
- **波形切换**:sw 直接参与组合选择,样本在 clk 沿锁存(切换即生效,无毛刺风险)

## 5. 人机交互

- SW0~SW1:00 正弦 / 01 方波 / 10 三角 / 11 锯齿
- S1 频率 +10Hz,S2 −10Hz;短按 = 按下到释放 <500ms
- 长按 ≥500ms 进入加速,每 100ms ±200Hz
- 钳位:10Hz ≤ f ≤ 1,000,000Hz(freq_hz 20bit)
- LED0~1:波形编号(二进制)
- LED2~7:频率粗刻度 `freq_khz[9:4]`(freq_khz = freq/1000;10Hz→0,16kHz→1,1MHz→62)
- 上电自动复位:50MHz 计数器产生 ~10ms 复位脉冲

## 6. 错误处理

- 无外部错误面(模块直插,无配置寄存器、无 I2C)
- 复位为上电自动复位;无外部复位键
- 若 DAC 无输出:检查模块电源(+5V 对插)、GPIO0 引脚映射、LVCMOS33

## 9. 风险与待办

- **ACM2108 官方管脚信息表(最高优先级)**:决定 GPIO0 引脚分配;未取得前按直接对插假设设计 XDC,板级核对一次
- MS9708 建立/保持时间裕量:50MHz 下数据提前 10ns 建立,充裕;若板级发现采样不稳,可把 DACLK 延迟再调半拍
- 1MHz 以上正弦质量受 8bit×50 点/周期限制,属预期(规格上限即 1MHz)
- 三角/锯齿满幅映射 ±127 与正弦 ±127 一致(三角峰值为 127−1=126 的舍入,无感知)
