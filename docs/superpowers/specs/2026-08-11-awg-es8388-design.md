# 任意波形发生器(AC820 / ES8388 音频输出)设计文档

- 日期:2026-08-11
- 板卡:芯路恒 AC820(xc7z020clg484-2,Zynq-7020)
- 工具:Vivado 2018.3 + `cli-anything-vivado` CLI
- 方式:纯 PL(无 PS/ARM),全部逻辑 Verilog,唯一 IP 为 clk_wiz

## 1. 目标

用 AC820 板载 ES8388 音频 DAC 实现一台简单的任意波形发生器:

- 4 种波形:正弦 / 方波 / 三角 / 锯齿(拨码 SW0~SW1 选择)
- 频率 20Hz~20kHz,10Hz 步进按键微调,S1 加、S2 减,长按加速
- LED 显示:LED0~1 波形类型,LED2~7 频率(kHz 二进制)
- 输出:3.5mm 耳机口(绿色,ES8388 LOUT1/ROUT1)
- 全部由 PL 实现,不涉及 ARM/SDK

## 2. 硬件上下文

### 2.1 板载资源(引脚速查)

| 信号 | 引脚 | 说明 |
|------|------|------|
| FPGA_GCLK | Y9 | 50MHz,`create_clock -period 20` |
| I2S_MCLK | W11 | ES8388 主时钟输入,12.288MHz |
| I2S_BCLK | R7 | 位时钟 3.072MHz |
| I2S_RCLK | U7 | LRCLK,96kHz |
| I2S_DACDAT | Y8 | DAC 数据(FPGA→ES8388) |
| AUD_I2C_SCL | G22 | I2C 时钟 |
| AUD_I2C_SDA | H22 | I2C 数据(开漏,inout) |
| S1 / S2 | H18 / H19 | 按键,按下为低 |
| SW0~SW1 | G21 / G20 | 波形选择,上拨=1 |
| LED0~7 | P20 P21 R20 R21 R19 T19 T16 T17 | 高电平点亮 |

全部 IOSTANDARD LVCMOS33。

### 2.2 ES8388 要点

- I2C 从机地址 0x10(7 位);写协议:START + 0x20 + [寄存器地址] + [数据],共 2 字节数据段
- 本次配置为 **I2S 从模式**(FPGA 出 MCLK/BCLK/LRCK),飞利浦标准格式,16bit,双声道
- 输出通道:LOUT1/ROUT1(原理图连接),耳机口输出;板载无扬声器默认配置
- 模拟输出无需 ADC 相关配置,但寄存器表按第 22 章实测序列照抄(含 ADC 部分,不影响)

## 3. 架构

```
50MHz(Y9) ──► clk_wiz ──► MCLK 12.288MHz(W11)
                │
                ├──► ÷4 ──► BCLK 3.072MHz(R7)
                ├──► ÷128 ─► LRCLK 96kHz(U7) ──► dds_core 采样使能
                └──► locked ──► 复位同步

dds_core(fs = 96kHz,每 LRCLK 一个 16-bit 样本)
  相位累加器 32bit:fword = 频率 × 2^32 / 96000
  正弦:256×16 ROM(BRAM,$readmemh 加载 tools/gen_sine.py 生成的 .mem)
  方波 = 相位最高位;三角 = 相位[30:24] 经 XOR 折返;锯齿 = 相位[30:24]
  SW0~1 选波形 → 16-bit 样本

i2s_tx:Philips I2S 串行发送器,16bit × 2 声道(左右声道同一样本)
  LRCLK 高 = 左声道,低 = 右声道;数据相对 LRCLK 边沿延迟 1 BCLK;MSB first

key_ctrl:按键去抖(~20ms)+ 短按 ±10Hz + 长按(>500ms)每 100ms ±200Hz
  频率钳位 [20, 20000]Hz;输出频率字 fword 与 LED 驱动

es8388_cfg:上电初始化状态机
  I2C 控制器 = ch20 的 i2c_control.v + i2c_bit_shift.v 原样复用
  配置 ROM = 第 22 章实测寄存器表(见 §5)
  全部写完 → done 标志;期间任何 NACK → ack_err(→ LED7 常亮)
```

### 模块清单(全部 Verilog-2001,可综合)

| 文件 | 来源 | 说明 |
|------|------|------|
| `awg_top.v` | 新写 | 顶层例化与引脚连接、复位同步 |
| `clk_wiz_12m288` | IP(唯一) | clk_wiz,50→12.288MHz,配置同第 22 章 |
| `dds_core.v` | 参考 ch15 | 相位累加器 + 波形生成 + 16-bit 量化 |
| `i2s_tx.v` | 新写 | Philips I2S 发送状态机 |
| `key_ctrl.v` | 参考 ch10 | 去抖 + 长按加速 + 频率寄存器 |
| `es8388_cfg.v` | 新写 | 上电配置状态机 + 配置 ROM |
| `i2c_control.v` | ch20 原样 | I2C 寄存器写控制器 |
| `i2c_bit_shift.v` | ch20 原样 | I2C 位级时序(SCL/SDA) |
| `sine_table.mem` | tools 生成 | 256×16 正弦表,十进制文本 |

## 4. 数据流与参数

- 采样率 fs = 96kHz(LRCLK = 12.288MHz / 128)
- 频率字:`fword = round(freq × 2^32 / 96000)`,freq=20Hz → 894,785;20kHz → 894,784,853(全量程 32bit)
- 正弦 ROM 地址 = 相位累加器高 8 位;16-bit 有符号输出(±32767)
- I2S 帧:BCLK 32 个/帧(LRCLK 周期 = 3.072MHz/96kHz),半帧 16 BCLK;Philips 标准:数据在 BCLK 下降沿变化,MSB 在 LRCLK 边沿后第 2 个 BCLK 上升沿被采样(1 BCLK 间隙,ES8388 数据手册明确);frame_edge 在 L 半帧起点(LRCLK 低→高)每周期脉冲一次
- 样本产生与串行发送同域(12.288MHz),LRCLK 边沿对齐采样
- 波形切换无毛刺处理:切换在 LRCLK 边界采样 Mode_Sel(寄存器同步)

## 5. ES8388 寄存器配置表(第 22 章实测,照抄)

I2C 写序列,严格按下列顺序逐条执行(每行 = 地址:数据;顺序与第 22 章 C 代码逐条一致):

```
0x00:0x80   0x00:0x00    ; 软复位(写 0x80 再写 0x00)
0x01:0x58   0x01:0x50
0x02:0xF3   0x02:0xF0
0x2B:0x80                ; ADC 与 DAC 共用 LRCLK
0x00:0x36
0x08:0x00                ; I2S 从模式
0x03:0x08                ; ADC 电源管理(暂不用 ADC)
0x04:0x00
0x0D:0x00                ; MCLK/fs 比率 128 → fs = 96kHz
0x18:0x00
0x05:0x00   0x06:0xC3
0x0A:0x00   0x0B:0x02    ; ADC 输入通道 LIN1/RIN1
0x0C:0x0C                ; ADC 控制:I2S 格式,16bit
0x17:0x18                ; DAC 控制:I2S 格式,16bit
0x10:0x00   0x11:0x00
0x1A:0x00   0x1B:0x00
0x09:0x00                ; ADC 增益
0x12:0x11                ; 关闭 ALC
0x13:0xC0   0x14:0x32   0x15:0x06   0x16:0xC3
0x27:0xB8   0x2A:0xB8
0x02:0x00
0x2E:0x1E   0x2F:0x1E   0x30:0x1E   0x31:0x1E   ; 四路音量,中等
0x04:0x36                ; DAC 电源使能 + LOUT1/ROUT1(bit5/4)+ LOUT2/ROUT2(bit3/2)
0x26:0x00
0x03:0x09                ; ADC 电源管理最终值
```

关键点:两处重复写入的寄存器(0x00/0x01/0x02 的"写两次"、0x04 的 0x00→0x36、0x03 的 0x08→0x09)顺序**必须**与上表一致;`0x04:0x36` 使能模拟输出通道,在其之前 DAC 保持掉电(避免上电爆音)。

## 6. 人机交互

- SW0~SW1:00 正弦 / 01 方波 / 10 三角 / 11 锯齿(上拨=1,带内部上拉)
- S1:频率 +10Hz;S2:频率 −10Hz;短按 = 按下到释放 <500ms
- 长按:按住 ≥500ms 后进入加速,每 100ms 再 ±200Hz(×20 步进)
- 钳位:20Hz ≤ f ≤ 20kHz
- LED0~1:波形类型(二进制)
- LED2~7:频率 ÷1000 的二进制值(20Hz→0,20kHz→20)
- LED7 兼作 I2C 错误指示:配置 NACK → 常亮

## 7. 错误处理

- 复位:clk_wiz locked 低有效复位 + 两级同步;无外部复位键
- I2C:ch20 控制器 ack 信号汇总,任何 NACK → ack_err 寄存器置位 → LED7 常亮;其余功能照常运行
- 无其他外部错误面(板载芯片接线固定)

## 9. 交付物与工程流程

```
<LOCAL_PATH>
├── docs/superpowers/specs/2026-08-11-awg-es8388-design.md
├── src/rtl/          *.v + clk_wiz 输出(IP 生成物)
├── src/constraints/  awg.xdc
├── src/tb/           awg_tb.v
├── tools/            gen_sine.py
└── README.md         使用说明(接线、操作、常见问题)
```

工程流程(CLI):

```bash
cli-anything-vivado project new awg <LOCAL_PATH> --part xc7z020clg484-2
cli-anything-vivado source add   awg/awg.xpr src/rtl/*.v
cli-anything-vivado constraint add awg/awg.xpr src/constraints/awg.xdc
# clk_wiz:CLI ip add 或 GUI 2 分钟创建
cli-anything-vivado synth run     awg/awg.xpr
cli-anything-vivado impl run      awg/awg.xpr
cli-anything-vivado bitstream generate awg/awg.xpr
cli-anything-vivado hw program   awg/awg.runs/impl_1/awg_top.bit
```

注意:工程路径全 ASCII;JTAG 下载前关闭 Vivado GUI。

## 10. 风险与备选

- clk_wiz 若在 CLI 流程不便创建:退回 50MHz÷4 = 12.5MHz MCLK、48.83kHz 采样率(纯分频,零 IP),寄存器 0x0D 改配比率 256(0x02)
- 若耳机音量过大/过小:调整 0x2E~0x31 音量寄存器(0x1E = 中等)
- 若长按加速手感不佳:调整 key_ctrl 的 500ms/100ms 参数
