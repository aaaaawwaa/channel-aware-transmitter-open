# 任意波形发生器优化:谐波合成 + 峰峰值显示(AC820 + ACM2108)设计文档

- 日期:2026-08-12
- 板卡:芯路恒 AC820(xc7z020clg484-2)
- 模块:小梅哥 ACM2108(双通道 8bit DAC MS9708)
- 工具:Vivado 2018.3 + SDK + `cli-anything-vivado` + Python 3(PySide6)
- 前置:建立于 `2026-08-12-awg-host-control-design.md`(PS 桥/无DDR/OCM/ASCII 协议全部沿用)与已交付的上位机控制版
- 核心实测数据:**幅度 100% 时示波器峰峰值 9.56~9.62V(方波 10kHz)**——Vpp 校准基准

## 1. 目标(三条优化需求)

1. **频率**:保留步进按钮(±10Hz、×10/÷10),手动输入支持单位后缀(`100000`/`100k`/`1.5M`/`250kHz`)
2. **谐波功能**:正弦输出可叠加最多 4 个谐波分量;每个分量独立设置**次数(2~8)**与**幅度(0~100%)**;基波幅度独立可调(默认 100%)
3. **幅值/峰峰值**:界面显示幅度条对应的 Vpp(`幅度% × 校准常数`),支持"按 Vpp 设置"反向换算,校准常数可调(默认 9.60V = 实测 9.56~9.62 中值)

## 2. 关键决策(已确认)

| 决策点 | 结论 |
|--------|------|
| 谐波作用对象 | **仅正弦**(wave=SINE 时输出谐波合成,其他波形原样) |
| 谐波规模 | 每通道 ≤4 个分量,次数 2~8(0=禁用) |
| 幅度语义 | 满幅百分比 + **Σ>100% 自动等比归一化**(由 PS 桥执行) |
| 合成架构 | **PL 实时合成**(方案 A):谐波相位累加器(fword×order)+ 查表 + 加权求和 |
| Vpp 呈现 | 百分比 + 实时 Vpp 显示;校准常数可调;支持按 Vpp 设置 |
| 频率输入 | 支持 k/M 后缀(解析在上位机 protocol.py) |

## 3. 总体架构

```
上位机(GUI)                        PS 桥                            PL
┌──────────────────┐   SET BASE/   ┌──────────────────┐   AXI GPIO   ┌─────────────────────────────┐
│ CH 面板:          │   HARMn ...   │ 状态表扩展:       │  6×32bit    │ reg_bridge 扩展              │
│ 基波幅度 A0(默认100)│─────────────▶│ 4×{order,ampl}   │ (3 个 IP)    │  → ch*_base + 4×{ord,ampl}   │
│ 谐波 1~4 次数/幅度 │              │ + base           │────────────▶│                             │
│ 幅度条(音量)       │              │ 归一化:Σ>100→等比 │             │ dds_core(基波四波形)          │
│ Vpp 显示+校准      │              │ 写寄存器+GET 一致 │             │ harm_synth(新,仅正弦):        │
└──────────────────┘              └──────────────────┘             │  base + 4 谐波累加器           │
                                                                   │  (步长 fword×order)          │
                                                                   │  查正弦表×幅度 → 求和          │
                                                                   │                             │
                                                                   │ wave=正弦 → sample=谐波合成    │
                                                                   │ 其他波形 → dds_core 原波形     │
                                                                   │ → ampl_scale(幅度条)→ DAC     │
                                                                   └─────────────────────────────┘
```

- **输出公式**(正弦):`sample = (base×A0 + Σ 谐波_i×A_i) / 100 × ampl% / 100`
- 归一化保证 Σ(base + Σharm) ≤ 100 → 中间值永不溢出 ±127
- 谐波仅正弦:wave≠SINE 时输出原波形,谐波配置保留(切回正弦即生效)
- 频率安全:order(≤8) × freq(≤1MHz) → fword×order ≤ 8×85.9M = 6.87e8 < 2^32,且 order×freq ≤ 8MHz ≪ 25MHz 奈奎斯特,全频段无混叠
- Vpp 与谐波无关:归一化后总峰值恒等于 ampl%,`Vpp = ampl% × 校准/100`

## 4. 寄存器与打包

**AXI GPIO 扩展:新增 2 个双通道 IP(共 3 个 IP、6×32bit 全输出,PS 只写)**

| 通道 | 内容 |
|------|------|
| ch0 | CH1:`freq[19:0] \| ampl[7:0]<<20 \| wave[1:0]<<28`(不变) |
| ch1 | CH2:同上(不变) |
| ch2 | CH1 谐波字 A:`{base[7:0], h2_amp[6:0], h2_ord[3:0], h1_amp[6:0], h1_ord[3:0]}` = 30bit |
| ch3 | CH2 谐波字 A:同上 |
| ch4 | CH1 谐波字 B:`{reserved[9:0], h4_amp[6:0], h4_ord[3:0], h3_amp[6:0], h3_ord[3:0]}` = 32bit |
| ch5 | CH2 谐波字 B:同上 |

- `ord[3:0]`:0=禁用,2~8 有效(4bit 覆盖,可扩展至 15)
- `amp[6:0]`:0~100(已归一化后的值)
- `base[7:0]`:基波幅度 0~100(已归一化)
- **全 0 退化(实现确认)**:谐波字 A/B 全 0 且 wave=SINE 时,PL 退化为纯基波路径(dds_core 原正弦,等效 base=100)——保证未配置/PS 未写入时仍有默认输出;静音统一由幅度条 ampl=0 实现(与上电默认"双保险"一致)
- 每通道谐波配置**一次 32bit 写入原子生效**(字 A 含 base+h1+h2,字 B 含 h3+h4)
- PL 侧沿用 2-FF 同步(准静态参数)

## 5. 协议扩展(ASCII,向后兼容)

| 命令 | 说明 | 响应 |
|------|------|------|
| `SET CH1 BASE 100` | 基波幅度 0~100 | `OK` / `ERR BASE OUT OF RANGE` |
| `SET CH1 HARM1 ORDER 3` | 谐波 n(1~4)次数 0|2~8 | `OK` / `ERR HARM ORDER OUT OF RANGE` |
| `SET CH1 HARM1 AMPL 30` | 谐波 n 幅度 0~100 | `OK` / `ERR HARM AMPL OUT OF RANGE` |
| `GET CH1` | 扩展回读 | 见下 |

`GET CH1` 响应(向后兼容:新字段追加在末尾):

```
CH1 WAVE SINE FREQ 100000 AMPL 80 BASE 100 H1 3 30 H2 0 0 H3 0 0 H4 0 0
```

**桥内归一化(任何 BASE/HARM 写入后执行):**
- `sum = base + Σharm_ampl`;若 `sum > 100` → 每个分量 `×100/sum`(整数除法截断);`sum == 0` → 全部写 0(PL 端该配置退化为纯基波,见 §4)
- GET 返回**归一化后**的值(与 PL 输出一致)
- 旧命令(SET WAVE/FREQ/AMPL)与旧 GET 字段完全不变

## 6. PL 改动

### 6.1 新模块 `harm_synth.v`

```
端口:clk, rst_n, fword[31:0], base[7:0],
     h1_ord[3:0]..h4_ord[3:0], h1_amp[7:0]..h4_amp[7:0]
输出:reg [7:0] sample(有符号,Σ归一化后 ∈ ±127)
内部:
  - 5 个 32bit 相位累加器(基波 + 4 谐波);谐波 k 累加步长 = fword × ord_k(36bit 积取低 32)
  - 5 个 sine_rom 查表(256×8 补码 ±127,例化 5 份)
  - 每路 `sine × amp/100`(复用 ampl_scale 常数除法模式,截断)
  - 5 路求和(10bit 有符号)→ 截断回 8bit(归一化保证 ≤±127,截断纯防御)
  - 流水 ~4 拍
```

- ord=0 的谐波:步长为 0(输出恒定 0 分量,等效禁用)
- 与 dds_core 累加器同 fword、同初值 → 相位天然同步

### 6.2 `reg_bridge.v` 扩展

- 新增输入 `gpio2_in..gpio5_in`(2-FF 同步,同现有模式)
- 拆包:每通道 `base[7:0]` + `h1..h4 {ord[3:0], amp[7:0]}`
- 输出:`ch*_base`、`ch*_h_ord[3:0]×4`、`ch*_h_amp[7:0]×4`

### 6.3 `awg_top.v` 改动

- 每通道:`wave==SINE ? harm_synth(合成输出) : dds_core 原波形`(组合选择,沿同步)
- 合成输出过 ampl_scale(幅度条)→ dac_driver;LED 不变

### 6.4 资源预估

每通道 harm_synth ≈ 5 累加器(~160 FF)+ 5 ROM(~640 LUT)+ 5 乘法/除法(~250 LUT);双通道新增 ~1.5~2k LUT + ~0.5k FF。当前 LUT 2.2% → ~6%,无压力。

### 7.1 CH 面板扩展

```
┌ CH1 — DAC0 ─────────────────────────────────┐
│ [正弦][方波][三角][锯齿]                      │

│ 谐波3 次数 [关 ▾] 幅度 [-----] 0%             │
│ 谐波4 次数 [关 ▾] 幅度 [-----] 0%             │
│ 幅度 [========●====] 80%  ≈ 7.68 Vpp         │  ← Vpp 实时显示
```

### 7.2 交互逻辑

- 谐波 4 行:次数下拉(关/2~8)+ 幅度滑块(0~100%,关闭时禁用);基波幅度滑块(0~100%,默认 100)
- **归一化提示**:Σ>100% 时面板顶部显示"已自动归一化(总幅 145% → 100%)"
- **Vpp**:幅度条旁 `≈ X.XX Vpp`(= 幅度% × 校准/100);"按 Vpp 设置"输入 → 反算 % 并移动幅度条;校准常数 QDoubleSpinBox(0.1~20V,默认 9.60)
- **频率输入**:`parse_freq_input()` 在 protocol.py,支持 `100k`/`1.5M`/`250kHz`/纯整数,带 pytest
- **波形预览**:wave=SINE 且谐波未全关时,绘制 `Σ(base×sin + Σ谐波)` 理论波形(谐波编辑实时刷新);谐波全关/其他波形 → 原预览
- **状态回读**:GET 扩展字段(含 BASE/H1~H4)同步界面,断线重连完整恢复

## 8. 错误处理

| 层 | 处理 |
|----|------|
| PS 桥 | BASE>100 / HARM 次数>8 或 =1 / HARM 幅度>100 → ERR 拒绝,不写寄存器;归一化整数截断 ≤1% 误差(8bit 无感知) |
| 上位机 | 相同校验前置(protocol.py ValueError);Σ>100 界面提示归一化;Vpp 输入超量程提示并钳位 |
| PL | 纯组合+寄存器,无外部错误面;合成截断纯防御 |

## 11. 风险与待办

- **新 AXI GPIO IP**:地址由 assign_bd_address 自动分配;SDK 侧 XPAR_AXI_GPIO_1/2_* 宏自动生成(桥代码用宏名,不硬编码地址)
- **归一化截断**:整数除法 ≤1% 误差,8bit DAC 无感知
- **高次谐波质量**:8 次谐波在低频(≤10kHz)下每周期点数充足;1MHz 时 8 次谐波 ≈ 6.25 点/周期,波形粗糙但属规格内(谐波功能主要面向低频)
- **相位同步**:谐波累加器与基波同初值同 fword,无需额外同步逻辑
- **向后兼容**:旧命令/旧 GET 字段不变;旧上位机忽略追加字段(解析器已按 token 循环)
