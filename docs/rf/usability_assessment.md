# AD9361 可用性与可集成性评估（归档）

- **日期**：2026-09-18
- **状态**：结论已归档；**门禁未通过**，见 §3
- **上游**：`docs/superpowers/specs/2026-09-17-ad9361-tx-bringup-design.md`（binding）、
  `docs/rf/boardtest.md` §6–§9、`docs/rf/l2_stage1_record.md`
- **本文性质**：把"AD9361 现在能不能用、能不能并进 AWG"这个问题**结一次账**，并写清
  **这个结论在什么条件下会被推翻**。不引入任何新测量。

---

## 1. 结论

三个判断，分开写，因为它们的判据不同、也**不该被合并成一个分数**：

| # | 判断 | 估计 | 判据（这个百分数在说什么） |
|---|------|------|---------------------------|
| J1 | **技术可行性** | **~90%** | AD9361 能不能在这块板子上、按我们说了算的方式，工作到可复现 |
| J2 | **能当 AWG 后端用** | **~50–60%** | 把 AWG 现在的功能**原样**搬到 RF 口上，需要补多少、补得动吗 |
| J3 | **值得现在就集成** | **否** | 现在动手，是**替换一个正在工作的东西**，不是补一个新功能 |

**J3 是唯一一个"决策"，J1/J2 是它的输入。** 下表是 J3 的理由，也是本轮明确推荐的行动：
**不集成，先把门禁（§3）过掉再说。**

## 2. J1 = ~90%：已经证明到什么程度

### 2.1 已经**测出来**的（不是推出来的）

| 层 | 判据 | 实测 | 出处 |
|---|------|------|------|
| L1 控制面 | `PRODUCT_ID` / `REG_CTRL` 回环 / 14 寄存器逐条回读 | PASS（本板 `0x0A` = rev2） | `docs/rf/boardtest.md` L1 章 |
| L2 阶段一 Step 0–3 | C 传输层复现 L1 三条 + `plstate` 否定判据 | PASS | `docs/rf/l2_stage1_record.md:36-46` |
| L2 Step 4 | 判据 4.1–4.6（谱线存在性 / Δf 线性 / fs↔DATA_CLK / LO 平移 / 衰减差值） | PASS | `docs/rf/l2_stage1_record.md:212-286` |
| L2 Step 5 | 回读审计（第二次 SPI 遍历） | PASS | `docs/rf/l2_stage1_record.md:336` |
| L3 阶段二 | 判据 5.1/5.2/5.3（1R1T→2R2T，TX1 音**不翻倍**，TX2 出载波） | PASS | `docs/rf/boardtest.md:698-712` |

关键数字（都在上面那几处）：**80 MHz 载波 snr 41.3 dB**；单音 **4.992 MHz**；切到 2R2T 后
TX1 仍是 **1872.0 kHz**（比值 `2.0000` 的反面证据 —— 若任一环节没跟上就会变 3744）；衰减
10000→30000 mdB 实测差 **19.85 dB**（判据 20±3）。

**为什么这些数字值 90% 而不是 60%**：判据 5.3 是**双向咬合**的。2R2T 下 DATA_CLK 翻倍
（120→240 MHz）而 strobe 分频器同时翻倍（2→4），**两个效应严格抵消**，所以 TX1 的音**必须**
停在 1872.0 kHz。实测停住了 ⇒ 一次性证明了 BD 网表、`dds_ce` 周期、和 AD9361 的真实采样率
**三者同时对**。这不是"看到个信号"级别的证据。

### 2.2 为什么停在 90 而不是 100

| 未覆盖 | 为什么这限制结论 |
|--------|-----------------|
| **只有一个 LO（80 MHz）、一个 fs（60 MSPS）** | 参数鲁棒性完全没测。80 MHz 是**被仪器逼出来的**（§4.4），不是器件需求 |
| **用的是厂商驱动** | 一次 PASS 证明的是**我们的传输层**（PL SPI master + 模式引脚 GPIO + LVDS TX + PL DDS），**不证明**我们对 AD9361 寄存器语义的理解 —— 这条已写进设计 §5.6 |
| **RX 数据面不存在** | `ad9361_phy` 的 RX 输出在 BD 里悬空，RF overlay 无 BRAM、无 DMA（`docs/rf/boardtest.md:601`） |
| **I/Q 顺序与镜像抑制 = NOT RUN** | Q 恒 0（`rf_tx_source.v:109-111` 两种模式下都是），输出是双边带，没有"哪一侧"可看 |
| **判据 C3 在**两个**模式下都不可信** | 1R1T 那次是**假识别**（命名了一个不存在的 `fs = 3 × f_DATA_CLK`），2R2T 那次是候选集缺 0.25 的**结构性 FAIL**。已按项目规矩记 **NOT RUN for purpose**，没有动阈值让它变绿（`docs/rf/boardtest.md:724-745`） |
| **观测通道自己有一个已知缺陷** | `f_DATA_CLK` 的 16 位窗计数器折回，>99.997 MHz 整体折回（`docs/rf/boardtest.md:320-344`）。120/240 MHz 都是**加上 65536 的整数倍反推**出来的 |

### 2.3 什么会把 90 打下去

- 换一个 LO 就出问题（例如 LO 变化改变 TX 链增益）⇒ 说明现在这条通路是**特例**不是**器件**；
- 上 RX 之后发现 I/Q 顺序或镜像抑制不可接受 ⇒ 器件可用但**不能做复数调制**，而这正是数字调制链的全部前提；
- 连续流式（不是周期单文件）跑出 underflow 或不可复现的相位 ⇒ J2 会一起掉。

## 3. 门禁（J2 的 DoD）：补 TX 数据通路

**这是"完整验证可行"的定义，也是示波器边界探索（`docs/rf/scope_limits.md` §4）的放行条件。**

### 3.1 已完成的门禁

| # | 项 | 状态 |
|---|----|------|
| G0 | TX 侧能发出可解释的射频信号 | ✅ 2026-09-18 完成（L2/L3 全 PASS） |
| G1 | 两个 TX 通道都由软件可判 | ✅ 2026-09-18 完成（阶段二 2R2T，判据 5.1–5.3） |

### 3.2 未完成的门禁 —— **本轮的唯一结构性缺口**

> **PS → PL → AD9361 之间没有任何样点通路。** 不是"通路不够宽"，是**通路不存在**。

证据：

| 事实 | 出处 |
|------|------|
| `ext_dac_valid` / `ext_dac_d1` / `q1` / `d2` / `q2` 五个输入**全部**挂在 `xlconstant` 的 0-valid/0-data 上 | `rf_overlay/bd/create_bd.tcl:102-115`（原文注释：「The external input is parked on a constant 0-valid / 0-data bundle. When the AWG side is migrated onto RF this is what gets rewired to the real source」） |
| `tx_mode_dds` 常量 = 0（永远选 DDS 音，`mode` 端口不可写） | `rf_overlay/bd/create_bd.tcl:189-191` |
| RF overlay 里**没有** BRAM、**没有** DMA、**没有** 任何 AXI 通路能看见一个采样点 | `docs/rf/boardtest.md:601` |
| BD 里只有 3 个 AXI 从机（`axi_ctrl_0` / `pl_spi_0` / `axi_gpio_ctrl`），全是 AXI-Lite 控制面 | `rf_overlay/bd/create_bd.tcl:199-207` |
| `S_AXI_HP0` 在 PS7 配置里是 disabled | `rf_overlay/bd/ps7_props_rf.tcl:16-20`（原文：「this overlay has no HP master at all」） |
| Q 恒 0 | `rf_overlay/rtl/rf_tx_source.v:109-111` |

### 3.3 门禁的完成定义（可判、可证伪）

全部满足才算过；每一条都要**在测量前**写死判据：

| # | 条件 | 怎么判 | 怎么证伪 |
|---|------|--------|---------|
| **D1** | PL 里有一条 PS→AD9361 的样点通路（DMA 或 BRAM 均可） | `ext_dac_*` 不再是 `xlconstant`；`mode` 可写；BD 里出现真实的数据搬运器 | 写一段**已知样点图案**，在 TX 上读出它 —— 读不出就是没通 |
| **D2** | **能发出非单音的波形** | 上位机指定 I/Q 样点序列（至少 64 点），TX 口上得到对应的调制波形 | 同一段数据换一个序列，输出**必须**跟着变 —— 不变说明 `ext_dac_*` 仍是死的 |
| **D3** | **速率关系被测量钉死** | 上位机给 `f_out`，示波器量到 `f_out`；改变**上位机侧**的样点数/速率，量到的频率按预期变化 | 这条**不能**用 `rf_tx_source.v` 的注释当依据 —— 本项目刚在 §0.1 吃过"注释自相矛盾"的亏 |
| **D4** | **I/Q 两路都活** | 给 Q 路喂与 I 路不同的数据，输出**必须**与 Q 恒 0 时不同 | 现在 Q 恒 0，所以"看起来有信号"不构成 I/Q 活的证据 |
| **D5** | 每一条新判据都能证伪 | 每条判据配一个 `PASS NV` 负例（本项目纪律） | — |

**明确不要求**（避免门禁膨胀）：RX 通路；连续流式（不是周期播放）的驻留；闭环 BER；
多文件无缝切换（`backend_contract.md` R3 明写这是两件事）。

### 3.4 已识别的一条捷径（**需你裁决，不是我可以自行采用的**）

把 AD9361 的采样率从 **60 MSPS 改成 50 MSPS**，DATA_CLK 变成 100 MHz(1R1T)/200 MHz(2R2T)，
于是与 AWG 链的 `sys_clk = 50 MHz`（`src/rtl/awg_top.v` 全链单一时钟，`Y9`）**一比一**：

| | 60 MSPS（现状） | 50 MSPS |
|---|---|---|
| 速率适配 | 需要 5/6 分数比转换 | **不需要** |
| AWG 的 PL 链 | NCO 频率字 / 抽头延迟 / 噪底标定**全部重算** | **原样搬过去** |
| 判据重标定 | `migration_plan.md:130` 那一串全要做 | 整块消失 |

**代价**：丢掉 10 MHz 奈奎斯特；`rx/tx_path_clock_frequencies` 要按 50 MSPS 重算（**未验证**）
—— 设计 §5.5 给的那组 `{1280M,160M,160M,80M,40M,40M}` 是 60 MSPS 的解。

**为什么我不采用**：这是与**规格**（binding authority，写的是 60 MSPS）和**例程参数**的偏离，
而你的常驻指令是"参数冲突先按例程为准"。所以它在这里只作为**待裁决选项**记录。
**注意**：`migration_plan.md:130` 那句"50MHz 的静态延迟不能不变地解释为新采样时标"正是这条捷径
要消掉的东西 —— 消掉它值不值，是这一轮该问的问题。

## 4. J2 = ~50–60%：当 AWG 后端用的四个缺口

### 4.1 缺口清单

| # | 缺口 | 严重度 | 现状证据 |
|---|------|--------|---------|
| **M1** | 样点通路不存在 | **阻塞级** | §3.2。这是 §3 那条门禁 |
| **M2** | 速率不匹配（50 MSample/s 8-bit 单路 vs 60 MSPS 12-bit I/Q） | 高 | AWG 全链单一时钟 `sys_clk` = 50 MHz；`migration_plan.md:125-126`：「**不能靠异步 FIFO 解决长期速率不匹配**」 |
| **M3** | Q 恒 0 | 高 | `rf_tx_source.v:109-111`。**RRC / 数字调制 / QAM 全部需要 I/Q 两路** |
| **M4** | 无 RX 通路 | **高（验收哲学层面）** | AWG 的验收靠**闭环 + 相对量**。RF 后端没有 RX 就无法闭环自证，只能靠外部仪器 |

### 4.2 但可复用的东西**比看上去多**

- **DMA→AXIS→FIFO 的流式模板在 AWG 侧已经跑通**（`scripts/create_bd.tcl:211-266`）：
  `axi_dma_0`（MM2S，32-bit，无 SG）→ `smartconnect` → `ps7_0/S_AXI_HP0`；
  `M_AXIS_MM2S` → `axis_data_fifo_0`（`IS_ACLK_ASYNC=1`，深度 4096）→
  `axis_dma_benchmark_sink_0` → `awg_top_0/user_stream_*`，带 underflow 回馈与校验和/水位 benchmark。
- 所以 RF 要加的**不是一个新数据面，是一个末端的速率/格式适配级**。
- 上层（Python 黄金模型、RRC 参数与验证算法、PRBS7、USER 字节流、队列/环播业务逻辑、
  七页 UI 与 draft/observed 事务）**全部与后端无关**，
  `docs/rf/backend_contract.md:228-229` 已明确"复用、不重写"。
- `backend_contract.md` §1 那张表里的六个抽象（`caps` 钩子 / 后台 job / backend 注入 /
  写者唯一 / 事务模型 / 只读状态读法）**已经为 RF 预留好了**（`ui_model.py:321` 的
  `caps = {"ad9361": False, ...}` 就是那个钩子）。

### 4.3 为什么是 50–60% 而不是 80%

- M1 是**结构性**的，不是调参能解决的：要动 BD、要重建位流、要写 PL 逻辑、要写用户态接口。
- M2 的分数比转换在**长期连续**流上会积累（文档已点名），不是加个 FIFO 就完事。
- M4 意味着**集成之后，那套让 ACM2108 路径可信的闭环验收方法在 RF 口上不能照搬** ——
  需要重建一套判据（`backend_contract.md` R1–R7 就是这套判据的草案，**尚未实现**）。
- M3 之外还有一条：`backend_contract.md:60-63` 明写「⚠ 停止 TX DMA **不保证射频口绝对无输出**」
  —— 这在 AWG 侧是"停就是停"的语义，RF 侧要单独验证并向用户如实报告。

## 5. J3 = 否：为什么现在不该集成

### 5.1 理由一：ACM2108 那条路**是全绿的**

| 套件 | 结果 | 出处 |
|------|------|------|
| `scripts/test_bridge.py` | **230/230 ALL PASS** | `CLAUDE.md`「测试速查」 |
| `scripts/scope_verify.py` | **61/61 PASS**（连跑三次） | 同上 |
| `host/.venv/.../pytest host/tests/` | **706 项全绿** | 同上 |
| `scripts/scope_verify_user.py` | **4/4 PASS** | 同上 |

集成 RF = **替换一个正在工作的东西**。按本项目的规矩，替换的门槛应该**高于**新增。

### 5.2 理由二：这台示波器**看不见 AD9361 的主要卖点**

AD9361 的价值在**调谐到 6 GHz**、**I/Q 正交**、**镜像抑制**。DSOX1102A 带宽 **100 MHz**
（`docs/superpowers/specs/2026-09-17-ad9361-tx-bringup-design.md:179`），LO 下限 70 MHz ——
所以这轮只能靠在 80 MHz 上，而这个频率上 AD9361 相对 ACM2108 + 外部上变频**没有任何优势**。

⇒ **RF 现在能给出的、ACM2108 给不了的，在这台仪器上测不出来。**

### 5.3 理由三：现在集成得到的是一半的功能

M1–M4 全在，且 M1 是阻塞级的。现在集成的结果是"用一套没改好的 RF 后端替换一套全绿的
ACM2108 后端"，净收益为负。

### 5.4 建议的行动

1. **先过 §3 的门禁**（补 TX 数据通路，D1–D5）。这是纯增量，不动 ACM2108 那条路。
2. 门禁过掉之后再重估 J2 —— 那时 M1/M2/M3 应当已消掉，J2 会跳到 80% 以上。
3. **裁决 §3.4 的 50 MSPS 捷径**（会决定门禁的规模）。
4. 按 `docs/rf/migration_options.md` 的对比矩阵定路线（用户已选"先并列评估再定"）。

## 6. 什么会改变结论

| 变化 | 对 J1 | 对 J2 | 对 J3 |
|------|-------|-------|-------|
| 补上 TX 数据通路（§3 门禁） | → 95% | → **80%+** | 需要重新评估 |
| 采样率改 50 MSPS（§3.4） | 不变 | → +10~15%（M2 消失） | 不变 |
| 加 RX 通路 | → 95% | → +10%（M4 消失，可闭环） | 不变 |
| 换一台 ≥1 GHz 带宽的仪器 | 不变 | 不变 | **可能翻转为"是"** —— 卖点变得可测 |
| ACM2108 路径出现无法解决的问题 | 不变 | 不变 | **翻转为"是"** —— 替换的相对成本下降 |
| LO 换一个频率就出问题 | **→ 显著下降** | 下降 | 更"否" |
| 上 RX 后发现 I/Q 顺序/镜像不可接受 | 下降 | **大幅下降**（数字调制链前提没了） | 更"否" |

## 7. 本评估**不**证明什么

| 不证明 | 为什么 |
|--------|--------|
| AD9361 在 80 MHz / 60 MSPS 之外的任何频率可用 | 只有一个 LO、一个 fs 被实测 |
| RX 可用 | RX 数据面不存在 |
| 我们对 AD9361 寄存器语义的理解正确 | 用的是厂商驱动 |
| I/Q 顺序 / 镜像抑制 | **NOT RUN**（Q 恒 0，无边带可选；且无 RX 接收验证） |
| RF 性能指标（EVM / 镜像 dB / 噪声系数） | 本轮不测 |
| 判据 C3 的结论 | C3 在两个模式下都不可信，已记 **NOT RUN for purpose** |
| 三个百分数是"测量结果" | 它们是**判断**，判据如上文逐条给出。**J1 有实测支撑，J2/J3 是工程估计** |
