## 2. 任务 1：独立 RF 基线

### 前置
- U1（模块型号）/ U2（原理图）/ U3（电平）**已闭**（2026-09-16，见 §1 与 `compatibility.md` §0.5）
- **查证：`axi-dmac` 是否必须重编内核**（`version_matrix.md` §3）—— **2026-09-16 已降级**：
  用户例程用 PS SPI + 自定义 PL 数据面跑通，**不碰 `axi-dmac`**，故这只是**路线选择**
  （`compatibility.md` §2.4）。若选 ADI 路线才需重编内核。

### 实现步骤

1. **建独立构建目录**（不碰现有 `awg/` 与 `pynq_overlay/`）：
   ```
   rf_overlay/          # 新目标，独立 build.tcl
   docs/rf/             # 本目录
   ```

2. **移植 PS7 配置**：从 `pynq_overlay/bd/create_bd.tcl` 抄 PS7 部分，
   **不抄 ADI 其他载板的 XDC 或 PS 配置**。

3. **加 `axi_ad9361` IP**（来自 ADI hdl 仓库）：
   - 注意 ADI 的 HDL 是 **Makefile 流程 + 版本绑 Vivado 分支**；
   - 本工程 2025.2 vs ADI `hdl_2026_r1`→2025.1，需确认能否直接打开 `.bd`；
   - 不能打开就把 IP 源文件移植过来，**记录 commit**。

4. **引脚约束**：从 `compatibility.md` 附二生成（Bank 34 数据面 `LVDS_25`、Bank 35 控制面
   `LVCMOS25`）。**电气阻塞已于 2026-09-16 解除**（P18 2.5V 档，实测 TP8=2.5V）——
   生成前先确认板上 P18 处于 2.5V 档、**绝不可拨到 3.3V 档**。

5. **设备树**：SPI 节点（驱动在，节点缺）+ AD9361 子节点。

6. **驱动**：out-of-tree 编 `ad9361.ko`（内核构建树在板端，符号已导出）。

## 3. 任务 2：Python I/Q 闭环与本地数据契约

### 前置
任务 1 通过。

### 实现
1. 复用 `host/siggen` 的 Python 黄金模型生成 QPSK + RRC 采样。
2. 经 `pyadi-iio` 发送，RX 采回，离线分析。
3. **区分 `PAYLOAD_BITS` / `IQ_SAMPLES`**（见 `backend_contract.md` §4）。
4. 数据页复用现有目录与队列，**只增加类型/元数据**。
5. 容量预算重新算（CMA 只剩 3.5MB）。
6. 顺序：单文件周期 → 有限多块 → 持续流。
   **不把 ADI cyclic buffer 伪装成 `DdrPp` 双 bank。**
7. 候选速率（**待驱动/时钟链确认**）：Rs=250kSym/s、RRC 4SPS=1MSPS、
   额外 4 倍插值至接口 4MSPS。

### 通过条件
- [ ] 已知数据每次重新捕获后**独立对齐**
- [ ] 报告有效比较比特数、错比特数、BER、EVM 测量条件
- [ ] 先 QPSK，再 16QAM/64QAM
- [ ] 记录 AGC 与 DC/IQ 跟踪校准开关（它们会改变被测损伤）

## 4. 任务 3：PL 调制链与 RF 数据接口适配

### 前置
任务 2 能可靠收发 QPSK。

### 实现
1. 找 **8-bit 量化前**的 I/Q 节点（若只能取 8-bit，明确有效精度仍是 8-bit）。
2. 给出位宽/小数位/舍入/饱和/使能/延迟表。
3. **分离三个时钟**：FPGA 逻辑时钟、RRC 样点率、RF 复数采样率。
   **不能靠异步 FIFO 解决长期速率不匹配。**
4. 查 `axi_ad9361` 的**真实端口**，不假定它接受任意标准 AXIS。
5. 设计配置提交、跨域握手、FIFO、复位、underflow/overflow 计数。
6. 逐层迁移：PRBS7 → QPSK → RRC → USER → 本地队列/DDR → 信道损伤。
   **每层重新计算**延迟秒数、NCO 频率字、噪声标定（50MHz 的静态延迟不能不变地解释为新采样时标）。
7. `AwgCtl`/`RingThread` 写所有权**不变**；RF 加自己的 DMA 适配器。
8. 用**带序号或可对齐的非重复载荷**检查连续性（不能仅凭 bank 切换/无欠载位判定无缝）。

### 通过条件
- [ ] 适配层 Python 定点与 RTL **逐样本一致**
- [ ] 随机 valid/背压与复位不丢样
- [ ] 时序/CDC 合格
- [ ] 原 ACM2108 分支回归仍通过
