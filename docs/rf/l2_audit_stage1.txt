How to read the verdicts
------------------------
CONFIRMED         read-back byte equals the last byte the trace says we wrote.
DECLARED-WEAK     the written byte was 0x00, so "read back 0" cannot distinguish
                  a landed write from one that never happened.  This is the
                  write-0 blind spot, reported rather than hidden.
DECLARED-VOLATILE an EXEMPT entry the part legitimately changes on its own.
UNEXPLAINED       differs, and is NOT covered by a declared exemption.  This is
                  the audit's most valuable output -- see the analysis below.
