## 2. 来源与整理规则

1. **数字只从原件照抄**，保留原文限定语；不换算百分比、不把估计值写成实测、不把历史候选指标移植到当前交付版本。
2. **每份摘要在文首给出报告头**（工具版本/器件/速度等级/设计状态/日期）与**原件 SHA-256**，便于用原件复核。
3. **原件路径抽象化**：公开文档只写 `<LOCAL_EVIDENCE>/…`。原件报告头里含开发机主机名与绝对路径，摘要中已剔除，不复制到公开副本。
4. **冲突不调和**：两份原件对同一量的记载不同（如 `data_clk` WHS `0.066` vs `0.349`；RF 板级 WNS `12.359` vs `12.710`）时，两个值都列出、指明出处，不擅自选择一个"正确值"。
5. **历史与旁路材料单列**：QAM64 时代报告、辅助 AWG 指标、其他候选（`b82b141e`、`399b300e`、`aba80e92`、`4814bbc4` 等）只作为**历史记录**引用，均不冒充当前 RF 交付结果（边界见 EVIDENCE-PACK §6）。

## 3. 使用限制（必须保留）

- **不能复算**：本仓库没有 Vivado、没有位流/HWH、没有原始 IQ、没有原始收据；摘要中的任何数值都不能在本副本内重新计算或重新测量。
- **不能外推**：每条结果只对其版本、日期、条件成立；不得用于新候选、新日期或未测模式。
- **不能当验收**：摘要是"文档级"引用；`NOT_RUN`、`NOT_MEASURED`、`NOT_IMPLEMENTED` 保持原样，不改写成通过。
- **不证明**：内部时序满足 ≠ 外部 RF DDR 接口满足（接口无 I/O delay 约束，见 merged 摘要 §7）；工具估计功耗 ≠ 板上实测功耗。

## 4. 回查方式

1. 在本目录找到对应摘要，记录文首"原件"路径与 SHA-256；
2. 在开发机 `<LOCAL_EVIDENCE>` 下按路径取原件，用 `sha256sum`/`Get-FileHash` 核对哈希；
3. 打开原件报告，按摘要的"章节/表名"核对数值与限定语；
4. 若原件与摘要不一致，**以原件为准**，并在新文档中记录差异（不要就地改旧摘要）。
