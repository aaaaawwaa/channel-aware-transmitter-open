# 电平预算（计算界，不是测得 dBm）

## 口径

- 参考：ADI FMCOMMS3/AD9361 满幅 CW 输出约 +8 dBm（特定工作点）。本预算用 **+10 dBm 作为保守上界**，即比参考再高 2 dB。
- 接收端绝对最大输入：Pluto/AD9361 资料给 +2.5 dBm。本预算对 Pluto RX 与板卡 RX 都用 **+2.5 dBm**，不假设板卡前端更好。
- 线缆/接头损耗按 **0 dB** 计（最坏情况）；实际有损耗只会让裕量更大。没有外置衰减器。
- 数字幅度按**峰值码/2047**折算：板卡 60/2047 = -30.66 dB；Pluto 0.1 = -20.00 dB。
- 所有 dBm 都是**由上述参考值推算的界**，不是功率计/示波器/接收机校准结果。rms_iq 是归一化 IQ，不是 dBm。

## 方向 A：板卡 TX1 -> Pluto RX

| 项 | 值 | 说明 |
|---|---:|---|
| 保守 TX 满幅上界 | +10.0 dBm | 比 +8 dBm 参考高 2 dB |
| 板卡内部 TX 衰减 | -46.0 dB | 冻结门 46000 mdB |
| 满幅最差输入 | **-36.0 dBm** | 不乘数字幅度；用于保守界 |
| 数字幅度 60/2047 | -30.66 dB | config/diagnostic.json board.amplitude=60 |
| 实际配置输入 | **-66.66 dBm** | -36.0 - 30.66 |
| Pluto RX 最大输入 | +2.5 dBm | 资料值 |
| 满幅最差裕量 | **38.5 dB** | 2.5 - (-36.0) |
| 实际配置裕量 | **69.16 dB** | 2.5 - (-66.66) |

结论：即使假设板卡满幅 +10 dBm 且线损为 0，Pluto RX 仍有 **38.5 dB** 的保守裕量；按实际 60 码配置约 **69.2 dB**。这不能证明没有损伤风险，只说明在“内部 46 dB 确实生效”的前提下预算充足；46 dB 是否生效由发射前回读门负责。

## 方向 B：Pluto TX -> 板卡 RX1

| 项 | 值 | 说明 |
|---|---:|---|
| 保守 TX 满幅上界 | +10.0 dBm | 同上 |
| Pluto 内部 TX 衰减 | -60.0 dB | 起点 60 dB；上限 89.75 dB |
| 满幅最差输入 | **-50.0 dBm** | 不乘数字幅度 |
| 数字幅度 0.1 | -20.00 dB | config/diagnostic.json pluto.amplitude=0.1 |
| 实际配置输入 | **-70.0 dBm** | -50.0 - 20.0 |
| 板卡 RX 最大输入 | +2.5 dBm | 资料值 |
| 满幅最差裕量 | **52.5 dB** | 2.5 - (-50.0) |
| 实际配置裕量 | **72.5 dB** | 2.5 - (-70.0) |

结论：按满幅 +10 dBm、0 dB 线损的最差假设，板卡 RX 仍有 **52.5 dB** 保守裕量；按 0.1/60 dB 配置约 **72.5 dB**。

## 阶段 0：Pluto TX -> Pluto RX 自回环

与方向 B 的发射侧相同：60 dB + 0.1，最差 -50.0 dBm，配置 -70.0 dBm；Pluto RX 最大 +2.5 dBm，因此满幅裕量 **52.5 dB**，配置裕量 **72.5 dB**。

## 这些界没有覆盖什么

1. **没有实测板卡/Pluto 的绝对输出功率**；+10 dBm 是保守参考，不是本机测量。
2. **没有覆盖外置 PA**：若板卡或 Pluto 实际带 PA，必须按实际模块重新计算；本预算不能沿用。
3. **没有覆盖频率相关的增益/损耗**：433.9 MHz 的前端匹配、线缆损耗、接头损耗都未测；0 dB 线损是最坏假设，但频率响应不是。
4. **没有覆盖 LO 泄漏/杂散**：内部衰减通常同时衰减信号与泄漏，但不能用本预算证明杂散低于某个绝对值。
5. **没有覆盖接收端压缩/AGC**：Pluto RX 固定手动 0 dB；板卡 RX 沿用既有设置，未在本轮改动。即使输入低于绝对最大，也可能出现 ADC/前端压缩，必须靠 CLIPPED/峰值/饱和检查停。
6. **示波器不参与**：DSOX1102A 70/100 MHz、1 MΩ，不能验收 434 MHz；它的电压读数不能换算本链路 dBm。

## 结论

在“内部衰减已在 RF 使能前生效并回读”的前提下，两个方向的保守输入裕量都大于 38 dB；但这不是功率测量，也不是损伤保证。任何回读不符、CLIPPED、异常峰值或线缆变动都必须停止，不能靠预算数字继续发射。
