# Overlay与AXI数据路径

## 构建与加载

- 保存构建输入、工具链版本、产物摘要和地址契约。先检查HWH中的IP、基地址和范围，再核对软件常量。
- 区分独立测试Overlay和产品合并Overlay；把独立bit覆盖到合并服务路径会丢失其他外设，不是软件导入问题。
- 查看运行服务谁加载Overlay，谁只映射已经加载的PL。不要让导入模块、状态轮询或验收脚本各自重载。
- 合法停止拥有者、确认无人使用PL后才进行一次受控重配置。服务恢复顺序由依赖关系决定，不能只看进程存在。

## MMIO、BRAM和数据格式

- MMIO偏移通常是**字节偏移**；数组索引和总线字节地址不可混用。先核对驱动API和BD配置，不机械多乘或少乘一次4。
- Xilinx BRAM控制器/块存储的地址选项会影响有效地址。若工程使用`Enable_32bit_Address`，核查实际BD属性及综合网表是否确实包含RAM；AXI握手成功且读回恒零不证明RAM存在。
- 从已知只读状态、普通可读写测试寄存器或隔离BRAM区域逐层定位：基地址→字节使能→地址递增→位宽→有符号解释→端序→I/Q打包。不要在有副作用寄存器上“试写看看”。
- `enable`、`arm`、`commit-toggle`和`wrap`是不同语义。记录具名位及改变前后值，不能用非零整体值推导“正在运行”。
- DMA/CMA不足先检查缓冲生命周期、占用者和实际可用内存；不默认重装PYNQ。处理缓存一致性、对齐和长度时遵循当前驱动约定。

## 时钟与吞吐

- 确认AXI时钟、采样时钟、复位释放、CDC以及BRAM读延迟。理想仿真使用的同源时钟不能替代真实接口时序验证。
- 分开测生成/拷贝、传输、分析、推理及显示耗时。主机速度不能代替ARM实测。
- 内部时序收敛不代表外部源同步I/O时序已约束；保留输入/输出延迟、运行期延迟配置、板级skew等未覆盖项。
- 配置回读只证明配置接口，不必然证明时钟到达、逐线延迟实际值或样本完整性。
